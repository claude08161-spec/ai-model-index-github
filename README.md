# AI Model Index

Актуальная статистика нейросетей в одном дашборде: кто где сильнее, сколько стоит
миллион токенов, как быстро отвечает и какой у модели контекст.
Снимок данных: **22.10.2026** (источники проверены 20–21.10.2026).

## Как открыть

Три способа, от простого к «как разработчик»:

1. **`standalone.html`** — весь сайт в одном файле (стили, данные и скрипты вшиты).
   Просто откройте двойным кликом в браузере: сервер не нужен, работает офлайн.
2. **`index.html`** — та же страница, но разложенная на файлы (`styles.css`,
   `data.js`, `app.js`). Тоже открывается двойным кликом: скрипты классические,
   без модулей и fetch, поэтому `file://` не мешает.
3. **Через локальный сервер** (нужно только если захотите дёргать данные по сети
   или подключить живой API):
   ```bash
   cd ai-model-index
   python3 -m http.server 8000
   # затем открыть http://localhost:8000
   ```

Шрифты Fira Sans / Fira Code подтягиваются с Google Fonts; без сети страница
аккуратно падает на системные шрифты — вёрстка не ломается.

## Как обновлять данные

Правится только `data.js`:

- `META.snapshot` / `META.sourcesChecked` — даты снимка;
- `MODELS[]` — по одной записи на модель: `arena` (Elo лучшей конфигурации + `arenaCi`,
  `votes`, `prelim`), `aa` (Intelligence Index), `bench` (BenchLM), `b{}` — бенчмарки
  (`swe`, `term`, `gpqa`, `mmluPro`, `arc2`, `hle`, `factual`, `liveReason`, `liveCode`,
  `mmmu`, `omniscience`, `webdev`, `sweM`, `gdpval`), `price{in,out,cache}`, `speed`,
  `latency`, `ctx`, `out`, `license`, `tier`, `released`, `badges`, `url`;
- `CATEGORIES[]`, `TIMELINE[]`, `SUBSCRIPTIONS[]`, `SOURCES[]`, `CAVEATS[]` — текст разделов.

Всё остальное (места в рейтинге, Парето-фронт, «лучшее значение в столбце»,
выводы сравнения, калькулятор) пересчитывается само при загрузке страницы.
После правок пересоберите single-file: `node scripts/build-standalone.mjs`.

Значение `null` = источник не публиковал число; ячейка покажет прочерк, а не ноль.

## Автообновление данных

`scripts/refresh_data.py` тянет машиночитаемые источники и точечно обновляет
в `data.js` только цены, цену кэша и размер контекста:

| Источник | Что берём | Статус |
|---|---|---|
| models.dev (GitHub, TOML-карточки вендоров) | цены вход/выход/кэш | авторитетный, если карточка первого лица и цена «каталожная» (≤2 знаков) |
| OpenRouter `/api/v1/models` | контекст, перекрёстная проверка цен | контекст принимается только если он больше текущего на >5% или текущий неизвестен |
| BenchLM, публичный CSV | перекрёстная проверка цен, контекст-заглушка | цена меняется только при согласии двух вторичных источников |

Защитные ворота: значения вне диапазонов отбрасываются; новые модели **никогда**
не добавляются сами — они падают в `data-candidates.md` на ручное одобрение;
расхождения без согласия источников помечаются в отчёте как «drift suspected»
и не трогаются. Отчёт каждого прогона: `reports/refresh-YYYY-MM-DD.md`.

```bash
python3 scripts/refresh_data.py           # сухой прогон: показать, что изменится
python3 scripts/refresh_data.py --apply   # применить + отчёт + кандидаты
```

Полностью автоматически (без рук) обновляется только слой «цены/контекст».
Слой редактуры — Arena Elo, Intelligence Index, бенчмарки, победители категорий,
хронология, примечания — остаётся ручным: стабильного API у этих данных нет,
а слепой скрейпинг ломается и тащит мусор. Это осознанное разделение.

### Автопрогон по расписанию
`.github/workflows/refresh.yml`: каждый понедельник 06:00 UTC GitHub Actions
гоняет скрипт с `--apply`, пересобирает `standalone.html` и коммитит изменения.
Netlify, подключённый к репозиторию, деплоит сам — сайт свежеет без вашего
участия. Кнопка ручной загрузки лежит в Actions → refresh-data → Run workflow.

## Тесты

```bash
npm i jsdom --no-save          # один раз
python3 -m http.server 8931 &  # сервер для теста
node tests/smoke.mjs           # рендер + сортировки + фильтры + сравнение + темы
```

Прогон проверяет: 58 строк таблицы, 33 точки scatter, 12 карточек категорий,
работу сортировок (aria-sort), поиска, всех фильтров, лимита сравнения в 4 модели,
переключателей графиков, калькулятора, темы, а также a11y-минимумы
(нет кнопок без подписи, у чекбоксов и точек графиков есть имена, есть skip-link).
